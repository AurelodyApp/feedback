# Aurelody Feedback

Aurelody 的公开反馈与功能建议。Aurelody 是为自建曲库打造的原生音乐播放器，支持 Jellyfin、Emby 与 Subsonic 兼容服务器（Navidrome、gonic 等），iPhone · iPad · Mac 通用。

Public feedback and feature requests for **Aurelody**, a native music player for your self-hosted library: Jellyfin, Emby and Subsonic-compatible servers (Navidrome, gonic…) on iPhone, iPad and Mac.

> 本仓库只用于反馈，不含 App 源码。
> This repository tracks feedback only. It does not contain the app's source code.

## 去哪里反馈 · Where to go

| 我想… · I want to… | 去这里 · Go here |
|---|---|
| 私下报告问题 · Report a problem privately | App 内 **设置 → 关于 → 发送反馈** · In the app: **Settings → About → Send Feedback** |
| 问「是 bug 还是我配置错了？」 · Ask "is this a bug or my setup?" | [Discussions · Q&A](https://github.com/AurelodyApp/feedback/discussions/categories/q-a) |
| 提功能建议、为别人的建议投票 · Suggest or vote on a feature | [Discussions · Ideas](https://github.com/AurelodyApp/feedback/discussions/categories/ideas)（用 👍 投票 · upvote with 👍） |
| 看更新与路线图 · Follow updates and the roadmap | [Discussions · Announcements](https://github.com/AurelodyApp/feedback/discussions/categories/announcements) |

Issues 由维护者从以上渠道整理后创建，请不要直接开 issue。
Issues are created by the maintainer from the channels above. Please don't open them directly.

## ⚠️ 发帖前请打码 · Before you post

这里的内容是公开的。Jellyfin / Emby 的 `api_key`、Subsonic 的 `u` / `t` / `s` 等链接参数**等同于你的账号密码**。截图、日志和链接里请删除或打码：

- 服务器地址（域名、IP、端口）
- 用户名，以及 `api_key`、`token`、`u`、`t`、`s` 等参数

Everything here is public. Link parameters such as Jellyfin / Emby `api_key` and Subsonic `u` / `t` / `s` **are as good as your password**. In screenshots, logs and links, remove or blur:

- your server address (domain, IP, port)
- usernames, and parameters such as `api_key`, `token`, `u`, `t`, `s`
