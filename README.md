# Aurelody Feedback

**English** | [简体中文](README.zh-CN.md)

Public feedback and feature requests for **Aurelody**, a native music player for your self-hosted library: Jellyfin, Emby and Subsonic-compatible servers (Navidrome, gonic…) on iPhone, iPad and Mac.

This repository tracks feedback only. It does not contain the app's source code.

## Where to go

| I want to… | Go here |
|---|---|
| Report a problem privately | In the app: **Settings → About → Send Feedback** |
| Ask "is this a bug or my setup?" | [Discussions · Q&A](https://github.com/AurelodyApp/feedback/discussions/categories/q-a) |
| Suggest a feature, or vote on one | [Discussions · Ideas](https://github.com/AurelodyApp/feedback/discussions/categories/ideas) (upvote with 👍) |
| Follow updates and the roadmap | [Discussions · Announcements](https://github.com/AurelodyApp/feedback/discussions/categories/announcements) |

Issues are created by the maintainer from the channels above, so please don't open them directly.

## Before you post

Everything here is public. Link parameters such as Jellyfin / Emby `api_key` and Subsonic `u` / `t` / `s` are as good as your password. In screenshots, logs and links, remove or blur:

- your server address (domain, IP, port)
- usernames, and parameters such as `api_key`, `token`, `u`, `t`, `s`
